Политика конфиденциальности

Дата вступления в силу: 05.09.2026

Мобильное приложение «Сила стали» (далее — «Приложение») принадлежит организации ООО «Сила стали» (далее — «Компания») и предназначено для внутреннего учёта работы сотрудников цеха. Настоящая политика описывает, какие данные обрабатываются и как они используются.

1. Какие данные обрабатываются

  • Учётные данные: логин (имя пользователя) и пароль, вводимые сотрудником при входе.
  • Данные о работе: сведения о выполненных работах, изделиях/деталях, количестве, нормах и сменах.
  • Личный ПИН-код (по желанию) хранится только на устройстве сотрудника в виде необратимого хэша (SHA-256) и не передаётся на сервер.

2. Куда передаются данные и где хранятся

Данные передаются и хранятся на сервере Компании (194.87.98.86). Доступ к данным имеют только сотрудники организации, использующие Приложение.

3. Цели обработки

  • Аутентификация сотрудников в системе учёта.
  • Регистрация выполненных работ и деталей для внутренней отчётности.
  • Расчёт статистики, норм и экспорт данных для администрации.

4. Передача данных третьим лицам

Данные не продаются и не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Безопасность

Пароли хранятся в виде хэшей. Приложение имеет внутреннюю систему учёта прав доступа (сотрудник, мастер, администратор). Связь с сервером осуществляется по протоколу HTTP; по мере развития серверной части Компания планирует переход на защищённое соединение HTTPS.

6. Удаление данных

Для удаления учётной записи или данных обратитесь к администратору Компании по адресу: [EMAIL АДМИНИСТРАТОРА]. Запись о работах может требоваться для внутренней отчётности, поэтому сроки удаления определяются правилами внутреннего учёта.

7. Данные детей

Приложение не предназначено для лиц младше 18 лет и не собирает данные детей.

8. Изменения политики

Политика может обновляться. Актуальная версия публикуется по адресу: [ССЫЛКА НА ЭТУ СТРАНИЦУ].
